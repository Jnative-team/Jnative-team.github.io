Why JNative

Built for developers who want compiled-language performance without leaving the JVM ecosystem.

⚡

No JVM, No Warm-up

Bytecode is translated to SSA IR, analyzed, and lowered to LLVM. The executable starts instantly — no interpreter, no JIT, no class-loading overhead.

🧹

Static Lifetime Management

Interprocedural points-to and escape analysis classify every allocation site. Destructors are inserted at last use — deterministic cleanup without a garbage collector.

🔒

Memory Safety

Heap-escaped values are paired with null-outs so overwrite instrumentation cannot double-free. Shutdown cleanup uses a claim stack to break cycles safely.

📦

Broad Input Support

Plain JARs, directories, single CLASS files, and Spring Boot fat JARs — with lazy nested-JAR indexing and on-demand class loading.

🌐

Cross-Platform

Target triples for x86-64, AArch64, RISC-V, POWER, s390x, ARMv7, and i686. Override with --target and --data-layout.

🔧

GraalVM-Compatible Metadata

Reads reflect-config.json, proxy-config.json, jni-config.json, and resource-config.json under META-INF/native-image/.

Quick Start

Build a native executable from a JAR in one command.

terminal 
# Inspect a JAR
java -jar jnative.jar inspect app.jar

# Build a native executable (entry inferred from Main-Class)
java -jar jnative.jar analyze app.jar

# Choose entry, output, and dump analysis results
java -jar jnative.jar analyze app.jar \
  --entry com.example.Main \
  --output myapp \
  --alias --escape --lifetime --destructor

# Cross-compile for Windows
java -jar jnative.jar analyze app.jar \
  --target x86_64-pc-windows-msvc \
  -O3

# Generate LLVM IR without compiling
java -jar jnative.jar analyze app.jar \
  --entry com.example.Main \
  --no-compile

Memory Model

Every allocation site is classified at compile time. The runtime acts on that classification.

STACK

Does not escape its defining function. Eligible for stack allocation or full scalar replacement.

HEAP

Stored in another object’s field. A destructor is inserted at last use, and the containing field is nulled.

RETURN

Returned to the caller; the caller owns it. No cleanup inside the defining function.

GLOBAL

Reachable from a static field. Released during the cycle-safe shutdown pass.

THREAD

Handed to another thread. Not released per-use; lifetime is managed by the receiving thread.

UNKNOWN

The analysis cannot classify the site. Cleanup is handled conservatively.
